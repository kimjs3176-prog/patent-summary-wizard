# 웹 요약서와 동일한 PDF 다운로드

## 목표
PDF 전용 재조판 방식을 제거하고, 화면에 표시되는 AIS 웹 요약서 자체를 인쇄해 동일한 구성·색상·한글 글꼴로 저장되도록 변경합니다.

## 변경 사항
1. **PDF 다운로드 동작 전환**
   - 현재 별도 PDF 생성기를 브라우저 인쇄 기반 다운로드로 교체합니다.
   - 버튼을 누르면 웹 요약서 영역만 인쇄 대상으로 지정하고 인쇄 창을 엽니다.
   - 파일명에 특허번호가 반영되도록 문서 제목을 임시 설정한 뒤 복원합니다.

2. **웹 요약서 인쇄 최적화**
   - 화면의 제목, 특허 기본정보, 키워드, 사업화 점수·TRL, 도면, AI 요약, 출처, 종합 의견, 관련 특허, 규제 분석을 같은 순서와 시각 구조로 유지합니다.
   - 검색창, 메뉴, 액션 버튼, 공유 모달, 만족도 패널 등 요약서 밖 요소는 인쇄에서 제외합니다.
   - A4 폭, 페이지 여백, 페이지 나눔, 색상 보존, 한글 줄바꿈을 조정합니다.
   - 도면 확대 버튼은 인쇄 시 일반 콘텐츠처럼 보이도록 상호작용 효과를 제거합니다.

3. **중복 출력 구조 정리**
   - 숨겨진 구형 인쇄용 요약서와 PDF 전용 데이터 연결을 제거합니다.
   - 기존 인쇄 버튼과 PDF 다운로드 버튼 모두 동일한 웹 요약서를 대상으로 작동하게 합니다.

## 검증
- 일반 조회와 일괄조회에서 PDF 다운로드 버튼이 웹 요약서만 인쇄하는지 확인합니다.
- 데스크톱 인쇄 미리보기에서 한글, 색상, 도면, 카드 경계, 섹션 페이지 나눔을 확인합니다.
- 기존 웹 화면과 PPT 다운로드에는 변화가 없는지 확인합니다.
