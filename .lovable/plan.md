# 볼드 하이라이트 전략 재설계

## 목표
LLM이 직접 `**...**`를 출력하는 현재 방식은 통제가 어렵다. **AI는 볼드를 전혀 출력하지 않게 하고**, 클라이언트가 결정론적 규칙으로 의미 단위만 골라 하이라이트하는 구조로 전환한다.

## 핵심 원칙
1. **AI는 마크업 책임 없음** — 프롬프트에서 모든 볼드 지침 삭제, `**` 출력 금지
2. **클라이언트 측 의미 추출** — 정규식 기반으로 "정보가 있는 명사구"만 자동 강조
3. **보수적 적용** — 애매하면 강조하지 않음 (한 문단당 2~4곳)

## 자동 강조 대상 (우선순위 순)

### A. 정량 정보 (확정적)
- 수치+단위: `15%`, `2.5배`, `1,700억 원`, `7년`, `2013년`
- 비교 표현: `기존 대비 N배`, `약 N% 향상`, `최대 N`
- 서열번호: `서열번호 1`, `서열번호 1 내지 6`

### B. 고유명·전문용어 (사전+패턴)
- 학명 (이미 이탤릭 처리됨, 제외)
- 영문 학술용어: `Fibronectin 1`, `Matrix metallopeptidase 7`, `Lysyl oxidase`
- 약어 괄호식: `POCT`, `SNP`, `IPC`
- 균주명/품종명/물질명 (대문자+숫자 패턴)

### C. 차별적 효능·기능 명사구 (사전 매칭)
다음 패턴의 명사구만 강조:
- `[수식어] + 핵심명사` 형태 (예: `정밀 사양 관리`, `개체별 맞춤형 비육 전략`)
- 사전 어휘: `항균 활성`, `생체이용률`, `저독성`, `상관관계`, `정확도`, `안정성`, `완성도` 등
- 단, 일반명사 단독(기술/방법/시스템 등)은 절대 제외

### D. 비교·평가 결정어
- `세계 최초`, `국내 최초`, `최고`, `핵심`, `차별점`, `시장 안착의 핵심`

## 자동 강조 제외 (강한 금지)
- 모든 조사·어미·동사 어구
- 일반명사 단독 (기술, 방법, 단계, 분야, 영역, 본 기술 등)
- 격조사 포함 절(`...에서 확보`, `...를 구성`)
- IPC/CPC 코드
- 학명(이탤릭이 우선)

## 구현

### 1. 프롬프트 단순화 (`supabase/functions/summarize-patent/index.ts`)
- 기존 "볼드 처리 규칙" 블록 전체 삭제
- 새 지침 1줄로 대체: `"** 마크다운 볼드 표기를 사용하지 마라. 모든 강조는 시스템이 후처리한다."`
- 학명 이탤릭 규칙은 유지

### 2. 새 강조 엔진 (`src/lib/sanitizeBold.ts` 전면 교체)
- 기존 모든 규칙 삭제
- 새 함수 `applyHighlights(text: string)`:
  1. 기존 `**...**` 잔재 제거(안전망)
  2. 학명(`*...*`) 영역과 인용/각주 영역은 마스킹 후 건드리지 않음
  3. 패턴 A → C → D 순으로 매칭하며 `**...**` 삽입
  4. 같은 문단 내 중복 강조 방지
  5. 문장당 최대 2곳, 문단당 최대 4곳 상
