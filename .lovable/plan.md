# 특허 상태 뱃지 추가

## 구현 내용
- KIPRIS 조회 결과에서 등록 상태값을 함께 수집합니다.
- 상태값을 등록, 공개, 출원, 거절, 소멸, 취하, 포기, 무효 등 사용자 친화적인 명칭으로 정규화합니다.
- 요약서 상단의 기존 영문 상태 표시를 한국어 상태 뱃지로 교체합니다.
- 등록·공개·심사 중·거절/소멸 계열을 색상과 아이콘 점으로 명확히 구분합니다.
- 상태 원문이 없을 때는 등록번호, 공개일, 출원정보 순으로 안전하게 상태를 추정합니다.

## 기술 사항
- 특허 데이터 타입에 `legalStatus`를 추가합니다.
- 특허 조회 함수가 KIPRIS의 `registerStatus` 또는 `registrationStatus` 필드를 반환하도록 수정하고 캐시 버전을 갱신합니다.
- PDF 다운로드에도 동일한 상태 뱃지가 포함되도록 기존 요약서 화면 요소를 그대로 사용합니다.
- 타입 검사와 실제 요약서 화면에서 표시 상태를 확인합니다.
