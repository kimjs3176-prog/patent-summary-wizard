# 전문가 검토 기반 특허분석 개선

## 목적
AI를 특허마다 자동 재학습시키는 대신, **전문가가 확인한 수정 사례를 다음 분석의 참고자료로 활용**합니다. 모델 자체의 학습과 구분하며, 기존 TRL 기준·공식 시장 수치·점수 계산 규칙을 유지합니다.

## 1. 분석 수정 사례 수집
- 요약서에 ‘분석 수정 제안’을 추가합니다. 기존 만족도 평가와 구분합니다.
- 특허번호, 수정 대상(TR L이 아닌 TRL·시장 수치·기술 해석·사업화 평가), 기존 분석, 제안 내용, 근거·출처를 기록합니다.
- 의견은 모두 검토 대기로 저장합니다. 일반 이용자의 제안이 곧바로 다음 분석에 반영되지 않습니다.
- 제출 당시 분석과 모델·분석 기준 버전을 함께 남겨 나중에 변경 전후를 비교할 수 있도록 합니다.

## 2. 관리자 검토와 승인
- 관리자 화면에 검토 대기·승인·반려·적용 중단 목록을 추가합니다.
- 관리자는 근거를 확인하고, ‘무엇이 잘못됐는지 / 어떤 조건에서 어떻게 판단해야 하는지’를 정리해 승인합니다.
- 승인자와 변경 이력을 남깁니다. 승인 사례도 나중에 적용 중단할 수 있습니다.
- 근거 없는 수치, 단순 선호, 다른 특허에 일반화할 수 없는 주장은 참고 사례로 승인하지 않습니다.

## 3. 다음 분석에 검증 사례 반영
- 새 특허의 IPC 분야와 기술 내용에 가까운 승인 사례만 소수 선택해 요약·사업화 분석에 참고시킵니다.
- 사례는 판단 방법을 참고하는 자료입니다. 다른 특허의 TRL·시장규모·점수를 그대로 복사하지 않습니다.
- 특허 원문 근거와 공식 시장 통계, 기존 계산 규칙이 우선합니다. 사례만으로 실증·인증·판매 사실을 추정하지 않습니다.
- 적합한 사례가 없거나 조회가 실패하면 기존 분석 방식으로 진행합니다.
- 승인 사례가 바뀌면 관련 분석 버전이 바뀌도록 하여, 변경 전 저장된 결과가 새 기준의 결과로 표시되지 않게 합니다.
- 관리자는 각 분석이 참고한 사례를 확인하고, 사례 적용을 끈 결과와 비교할 수 있습니다.

## 4. 향상 여부 검증
- 참고 사례와 별개인 평가용 특허를 준비합니다. 같은 특허의 출원번호·등록번호는 하나로 묶어 양쪽에 중복되지 않게 합니다.
- 동일 모델·동일 원문으로 사례 적용 전후를 비교합니다.
- TRL 전문가 판정과의 차이, 시장 수치 계산 오류, 원문에 없는 주장, 전문가 수정 필요 여부를 항목별로 집계합니다.
- 평가용 특허의 정답은 분석 중 AI에게 전달하지 않습니다. 평가 결과는 자동 승인 근거가 아니라 관리자 검토 자료입니다.
- 검증이 끝나기 전에는 기본 적용을 끈 상태로 두고, 관리자가 결과를 확인한 후 활성화합니다. 문제가 생기면 즉시 중단할 수 있습니다.

## 적용 범위
- 우선 요약서와 사업화 분석에 적용합니다. 다른 분석 기능 확대나 모델 자체 미세학습은 이번 범위에서 제외합니다.
- 기능 구현 후에도 전문가가 승인한 사례와 평가용 정답을 제공하기 전에는 정확도 향상을 주장하지 않습니다.
- 사례를 추가로 참고하거나 전후 비교할 때 AI 사용량이 늘어날 수 있으며, 평가 실행은 관리자가 선택합니다.

## 기술 구현
- 기존 관리자 인증 흐름을 활용하되, 사례 승인·수정·중단은 서버에서 관리자 권한을 확인합니다.
- 검토 사례, 승인 이력, 평가용 정답은 비공개로 보관합니다. 공개 제출은 입력 검증·빈도 제한을 거치며 내부 자료 조회 권한을 주지 않습니다.
- 요약·사업화 분석이 동일한 승인 사례 조회 및 안전한 참고자료 구성 모듈을 사용합니다. 사례 본문은 명령이 아닌 자료로 취급합니다.
- 사례 적용 버전과 참고 사례 식별자를 분석 기록·캐시에 포함합니다. 전체 저장 결과를 일괄 삭제하거나 자동으로 유료 재생성하지 않습니다.
- 승인된 사례만 선택되는지, 비슷하지 않은 사례와 중단 사례가 제외되는지, 평가용 정답이 노출되지 않는지, 버전 변경이 반영되는지 테스트합니다.
- 실제 특허로 제안 제출 → 관리자 승인 → 새 분석의 참고 사례 확인 → 적용 중단 흐름을 검증합니다. 관리자 검증이 불가능하면 해당 항목은 미검증으로 명시합니다.
